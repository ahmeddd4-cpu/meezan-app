# تطبيق مِيزان (Meezan) — بلغة Rust 🦀

تطبيق منظم حياة شخصي متكامل للهواتف الذكية مبني بنسبة **100% بلغة Rust** باستخدام إطار عمل **Dioxus 0.6**، مع نظام حركة وانميشن سلس (`60fps/120fps`) ودعم كامل للغة العربية (`RTL`).

## أبرز المميزات
- **مكتوب بالكامل بلغة Rust:** إدارة الحالة (`Signals`)، التخزين المحلي (`serde_json`)، ومؤقت التركيز غير المتزامن (`async/await`).
- **انميشن وتفاعلات سلسة (Smooth Animations):**
  - انتقال صفحات انسيابي (`pageEnter`) بمنحنيات فيزيائية (`cubic-bezier(0.22, 1, 0.36, 1)`).
  - ظهور متتابع للبطاقات (`stagger-item`).
  - استجابة لمس نابضة (`tap-spring`) عند الضغط على الأزرار.
  - رسوم حلقية متحركة (`stroke-dashoffset`) لنسبة الإنجاز اليومي ومؤقت التركيز.
  - تعبئة مائية متحركة لأكواب الترطيب الـ 8 ونبض مستمر لعداد العادات (`🔥`).

## طريقة التشغيل والبناء للهاتف

1. **تثبيت أداة Dioxus CLI:**
```bash
cargo install dioxus-cli
```

2. **التشغيل الفوري للمعاينة:**
```bash
dx serve
```

3. **البناء كـ تطبيق Android أو iOS:**
```bash
# لبناء نسخة أندرويد:
dx bundle --platform android

# لبناء نسخة آيفون (على macOS):
dx bundle --platform ios
```
